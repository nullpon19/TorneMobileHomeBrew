# torne mobile HomeBrew エディション

Sony のサポート終了後も、公式ファームウェアの nasne をスマートフォンから操作し続けるための、非公式・個人開発のクライアントアプリです。iOS / Android / Mac / Windows / Linux に対応しています。

## 現状

v1.5.0 をリリースしました。配布物 (IPA / APK / Mac 版 / Windows 版 / Linux 版) は GitHub Releases から入手できます。

## 機能

- nasne の発見・登録
- 本体・HDD・チューナー等の情報取得
- 録画予約の一覧・作成・更新・削除 (録画先の内蔵 / 外付け HDD の選択、番組表の番組詳細からの予約作成にも対応)
- 録画タイトル一覧の表示 (200 件を超えるタイトルも全件表示、読み込みながら順次表示)
- 番組表 (EPG) の表示 (地デジ・BS 対応、放送中の番組のそのまま視聴、見ないジャンルの非表示、デスクトップ版ではドラッグでのスクロールにも対応)
- 録画の再生 (DTCP-IP、再生画質の選択: 元画質 / モバイル、シークバーと前後10秒ボタンによるシーク対応)
- ライブ視聴 (TV視聴): 放送中の番組をチャンネル一覧から選んで視聴 (地デジ / BS / CS のタブ切り替え、サブチャンネルの表示設定に対応。DTCP-IP、再生画質の選択: 元画質 / モバイル)
- 再生中の字幕表示 (ARIB 字幕) と、主音声 / 副音声の切り替え
- 録画タイトルの削除と、保護 (誤って消せないようにする) の切り替え
- 録画タイトル一覧の検索・並び替え・絞り込みと、サムネイル表示
- 録画再生のレジューム (中断した位置からの再開、公式アプリと再開位置を共有) と、早見再生 (1.25 / 1.5 / 2 倍速)
- 番組表のキーワード・ジャンル検索と、ジャンル別の色分け表示

### 録画の再生について

再生には DTCP-IP のデバイス資格情報 (DTLA 証明書と秘密鍵のペア) が必要です。**資格情報はアプリに同梱されていません。** 利用者自身の機器から得た自身のペアを、設定画面からインポートして使います (pydtcpip 形式の credentials.env ファイルを選んで読み込むこともできます)。インポート時に証明書の形式・DTLA 署名・秘密鍵とのペア整合を検証し、不正なものは保存しません。保存先は OS の保管庫 (iOS Keychain / Android Keystore) のみで、平文ファイルやログには残しません。セッション鍵はメモリ上でのみ保持します。

## 動作条件

- 公式ファームウェアの nasne (検証は FW 2.60)
- iOS 15.0 以降 / Android 7.0 (API 24) 以降（本フォーク版）
- nasne と同じ LAN に接続された端末

### Buffalo 製 nasne について

Buffalo 製の nasne には、現時点では対応していません。今後対応させていく方針ですが、現在はまともに動作しません。作者が Buffalo 製 nasne を所持していないため、対応は大幅に遅くなる見込みで、検証は所持している方の協力に頼ることになります。お持ちの方で検証にご協力いただける方がいらっしゃいましたら、Issue でお知らせください (協力者求む)。

## インストール

### iOS

署名なし IPA を配布しています。LiveContainer または AltServer 等でサイドロードしてください。

### Android

APK を直接インストールしてください (提供元不明アプリのインストール許可が必要です)。

### Mac (デスクトップ版)

Releases から Mac 版の zip をダウンロードし、展開してアプリを起動してください。署名はアドホックのため、初回起動時に確認が出る場合は右クリックから「開く」を選んでください。

Mac 版では再生のたびにキーチェーンのパスワードを聞かれる場合があります。その場合は「常に許可」を押してください。

### Windows (デスクトップ版)

Releases から Windows 版の zip をダウンロードし、展開して `TorneMobileHomeBrew-windows-1.5.0/tmhb.exe` を起動してください。

### Linux (デスクトップ版)

Releases から Linux 版の tar.gz をダウンロードし、展開して `TorneMobileHomeBrew-linux/tmhb` を起動してください。字幕対応の libmpv を同梱しているため、libmpv の別途インストールは不要です。実行には libepoxy と、音声出力用の libpulse / libasound が必要です。

## 使い方

1. アプリを起動し、「設定」タブで nasne を登録します。「LAN 内の nasne を探す」で発見できるほか、IP アドレスでの手動登録もできます。
2. 「ホーム」で本体・HDD の状態、「予約」で録画予約の管理、「録画済み」で録画タイトル一覧、「番組表」で番組表、「TV視聴」で放送中の番組の視聴が使えます。
3. 録画の再生は「録画済み」のタイトル詳細から、ライブ視聴は「TV視聴」のチャンネル詳細から行います。どちらの再生も、初回のみ設定画面で DTCP-IP 資格情報のインポートが必要です。

## 既知の制限

- iOS のサイドロード環境では SSDP による発見が動作しないため、「探す」ではサブネット走査が使われます。見つからない場合は手動登録をお試しください。
- 再生は nasne と同じ LAN での利用を想定しています。VPN 等の低速な経路では、録画のビットレートに転送速度が追いつかず、再生が一時停止することがあります。タイトル詳細で再生画質に「モバイル」を選ぶと、低ビットレート版で再生でき、一時停止を避けやすくなります。
- 番組表ではサブチャンネルを既定で表示しません (設定の「サブチャンネルを表示」で切り替えできます)。
- 字幕の DRCS 外字 (放送局独自の外字) は、Android 版では代替表示になります (iOS 版・macOS 版・Windows 版・Linux 版では表示できます)。
- LiveContainer で「マルチタスク」を有効にして起動すると、再生中のスリープ抑止が効かず、再生中でも端末がスリープする場合があります。その場合は、LiveContainer のアプリ設定で torne mobile HB の「マルチタスク」を「いいえ」にして起動してください (LiveContainer 全体のマルチタスク設定は変更不要です)。
